# Agent Notes

## Commit Message Standard

When Codex makes a commit in this repository, include agent metadata in the commit footer:

```text
Agent: Codex
Model: GPT-5.5 medium
```

Use a concise conventional-style subject when practical, for example:

```text
chore: update font loading strategy

Agent: Codex
Model: GPT-5.5 medium
```

Keep the footer factual and stable so later history can distinguish human-authored commits from agent-assisted commits.
